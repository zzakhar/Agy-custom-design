# Agy Custom Design (`agy-custom`)

Форк проекта [AsInsideOut/ag-custom](https://github.com/AsInsideOut/ag-custom). Модификация интерфейса Google Antigravity с управлением напрямую из чата через встроенный MCP-сервер и мгновенным Hot-Reload.

---

## 🚀 Быстрый запуск

### 1. Установка через Antigravity
Ничего скачивать руками не нужно. Просто скопируй ссылку на этот репозиторий и напиши агенту в чат:

```text
Склонируй https://github.com/USERNAME/Agy-Custom-Design и установи кастомный интерфейс
```

**Что сделает агент сам:**
1. Сам склонирует репозиторий через `git clone`.
2. Создаст резервную копию `app.asar.bak`.
3. Пропатчит `app.asar` (с расчетом SHA-256 integrity).
4. Зарегистрирует MCP-сервер управления в `mcp_config.json`.
5. Перезапустит Antigravity с рабочим Drag-and-Drop.

---

### 2. Управление из чата (без перезапуска)
Все изменения применяются на лету за 1 секунду:

* **Смена темы:**
  `Включи тему cerber` *(доступны: swiss, neon, linear, oled, cerber)*
* **Установка обоев:**
  `Поставь на фон C:\path\image.png (блюр 10, прозрачность 0.7)` *(поддерживает фото, GIF, MP4/WebM)*
* **Очистка фона:**
  `Убери обои`
* **Переименование моделей:**
  `Переименуй Flash в Gemini 4 Neon`
* **Маскот Anty:**
  `Скажи Anty: Код готов` или `Выключи маскота`

---

### 3. Откат к оригиналу
Если нужно вернуть чистый заводской интерфейс, напиши в чат:

```text
Откати интерфейс Antigravity к оригиналу
```
Агент восстановит `app.asar` из бэкапа и вернет настройки по умолчанию.

---

## Ручной запуск (альтернатива)

Если чат недоступен, можно выполнить вручную из папки проекта:
* Установка и перезапуск: запустить `apply_and_restart.bat`
* Откат: запустить `restore_original.bat`
* CLI-управление: `python agy_control.py status`
